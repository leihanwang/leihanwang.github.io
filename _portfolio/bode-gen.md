I work on improving **LLM-driven program synthesis** using Bayesian optimization. The project explores how to optimize prompts and demonstrations efficiently rather than running expensive optimization independently for every coding task.

Recent work uses a subset of **HumanEval+** tasks to build a compact memory of optimized prompt–exemplar pairs. An auxiliary LLM then selects task-specific demonstrations for unseen problems before the base model performs single-generation code synthesis.

**Research themes:** LLM4Code, Bayesian optimization, prompt optimization, program synthesis, task adaptation.
